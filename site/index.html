CommitPilot

IA para tus mensajes de commit, changelogs y Pull Requests — directamente desde la terminal.

Open Source · MIT BYOK Sin dependencias Node ≥18
Ver en GitHub → Instalar

¿Qué hace?

🧠 Mensajes de commit

Lee tu git diff y propone 3 mensajes con formato Conventional Commits.

📜 Changelogs

Agrupa tus commits en un changelog ordenado siguiendo Keep a Changelog.

🔀 Descripciones de PR

Genera el resumen, los cambios y los pasos de prueba de tu Pull Request.

🔐 Tú controlas tu clave

BYOK: usas tu propia API key de OpenRouter. Sin telemetría, sin intermediarios.

Instalación

# 1. Clona e instala
git clone https://github.com/juanpablofuentealba/commitpilot.git
cd commitpilot
npm link

# 2. Configura tu clave (BYOK, gratis en openrouter.ai/keys)
export OPENROUTER_API_KEY="sk-or-..."

# 3. Úsalo
git add .
commitpilot commit

# Salida:
  1. feat(auth): añade inicio de sesión con Google
  2. feat: integra OAuth de Google en el login
  3. feat(auth): soporta proveedor Google en autenticación
💡 ¿No tienes clave de OpenRouter? Crea una gratis en openrouter.ai/keys y pégala en la variable de entorno.

Comandos

commitpilot commit      # mensajes de commit desde el diff staged
commitpilot changelog   # changelog desde el historial
commitpilot pr          # descripción de Pull Request
commitpilot install-hook # hook automático en git commit
